# Sentiment Analysis Project

## Overview
Built a sentiment analysis model using TF-IDF and Logistic Regression on IMDB movie reviews.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- NLP

## Features
- Text preprocessing
- TF-IDF vectorization
- Sentiment prediction
- Confusion matrix visualization

## Model
Logistic Regression

## Accuracy
Around 89%
